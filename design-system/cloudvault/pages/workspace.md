# Workspace direction

The generated File Manager & Transfer system provides flat surfaces, accessible focus states and small consistent icons. For the document research workspace, use a quiet olive/sage palette with a deep forest action color, warm white surfaces and Manrope headings with DM Sans body copy. This intentional workspace override makes research feel calm and distinguishes it from a corporate storage dashboard.

- Primary #256653, white text; background #fdfefd; sidebar #f5f6f2.
- One upload action, predictable file navigation, independent research chat.
- Document preview and source-scoped chat appear together.
- Never disguise local lexical retrieval as semantic AI.
- All icon controls have accessible labels; native dialogs provide focus containment and Escape dismissal.
- Mobile navigation drawer, stacked viewer/chat, reduced motion support.
